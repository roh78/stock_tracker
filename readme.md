Stock Portfolio Tracker

Project Description:
This project is a simple Stock Portfolio Tracker developed using Python. 
It allows users to input stock symbols and quantities, then calculates the 
total investment value based on predefined stock prices.

Objective:
The main objective of this project is to understand and apply basic Python 
concepts such as dictionaries, loops, conditionals, user input, and file handling.

Features:
- User can enter multiple stock symbols and quantities
- Uses a dictionary to store stock prices
- Calculates individual and total investment value
- Displays portfolio summary on screen
- Option to save output in .txt or .csv file format

Technologies Used:
- Python (Core Programming)
- Concepts: Dictionary, Loops, Conditional Statements, Exception Handling, File Handling

How to Run the Program:
1. Open terminal or command prompt
2. Navigate to the project folder
3. Run the Python file using:
   python stock_tracker.py
4. Enter stock symbols and quantities as prompted
5. Type 'done' to finish input
6. View total investment result
7. Choose option to save file (txt/csv)

Sample Input:
AAPL → 2
TSLA → 1
MSFT → 3

Sample Output:
AAPL: 2 shares × 180 = 360
TSLA: 1 shares × 250 = 250
MSFT: 3 shares × 300 = 900

Total Investment Value: 1510

Files Included:
- stock_tracker.py (Main program file)
- portfolio.txt (Sample text output)
- portfolio.csv (Sample CSV output)
- output_screenshot.png (Execution screenshot)
- README.txt (Project description)

Conclusion:
This project demonstrates the basic working of a stock tracking system using Python.
It helps in understanding how data can be stored, processed, and exported using simple programming techniques.
